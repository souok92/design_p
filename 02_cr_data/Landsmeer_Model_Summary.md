# Landsmeer Model Summary

## Overview
Landsmeer (1958, 1963)는 손가락 관절의 운동학적 연결(kinematic linkage)을 설명하는 3가지 모델을 제안했습니다. 이 모델들은 힘줄이 관절을 가로지를 때의 기계적 거동을 설명합니다.

## Three Models

### Model I (가장 정확)
- **설명**: 힘줄이 관절의 곡면(curved articular surface)을 따라 미끄러짐
- **적용**: 신전근(extensor tendons)에 주로 사용
- **평가**: Armstrong & Chaffin (1978)이 실험적으로 가장 정확한 모델로 검증

### Model II
- **설명**: 힘줄이 직선에 가까운 경로를 따름
- **적용**: 특정 굴곡 조건에서 사용

### Model III
- **설명**: Model I과 II의 중간 형태
- **적용**: 복합적인 관절 움직임에 사용

## Landsmeer's Equation

힘줄의 순간 모멘트 암(instantaneous moment arm)과 관절 각도의 관계:

```
M = dE/dθ
```

**변수:**
- `M` = 순간 모멘트 암 (instantaneous moment arm)
- `E` = 힘줄 변위 (tendon excursion)
- `θ` = 관절 각도 (joint angle)

## Oblique Retinacular Ligament (ORL)

**Landsmeer's Ligament**라고도 불리며, PIP와 DIP 관절을 연결하는 사선 인대:

- **기점**: A2 pulley
- **경로**: PIP 관절의 회전축 복측(volar)을 비스듬히 통과
- **종점**: Terminal tendon의 측면 배측(dorsal)에 삽입
- **기능**: PIP 굴곡 시 DIP도 함께 굴곡시키는 메커니즘

## 데이터 해석

### ✅ 일치하는 점
1. **극도로 높은 상관관계** (r > 0.99): Landsmeer의 운동학적 커플링 이론 강력 지지
2. **DIP/PIP 비율**: 0.63-0.65는 문헌의 0.6-0.7 범위 내
3. **일관성**: 세 손가락 모두 유사한 패턴 → Model I의 보편성 입증

### ⚠️ 차이점
- 우리 데이터의 DIP/PIP 비율이 문헌(0.714)보다 약간 낮음
- 피험자들의 DIP가 PIP 대비 상대적으로 덜 구부러지는 경향
- 측정 조건의 차이 (동적 vs 정적, 자발적 vs 수동적 굴곡)
